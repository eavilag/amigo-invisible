# ADR-0014: CI/CD con GitHub Actions y token de API mínimo

**Estado:** Aceptado · **Fecha:** 2026-10-12 · **Decide:** Equipo · **Tipo:** Seguridad · **Requisitos:** RNF-10, RNF-11 · **Amenazas:** AME-13

## Decisión
- **CI** en cada *push* y *pull request*: instalación con `npm ci` (versiones bloqueadas), lint, tipos, unitarias, integración, E2E local, `npm audit --audit-level=high`.
- **CD** solo en `main` y tras pasar CI: migraciones D1 → `wrangler deploy` → pruebas `CP-P` contra producción.
- Secretos en *GitHub Actions secrets*: `CLOUDFLARE_API_TOKEN` (permisos **solo** *Workers Scripts: Edit* y *D1: Edit* sobre la cuenta) y `CLOUDFLARE_ACCOUNT_ID`.
- Acciones de terceros fijadas por versión mayor oficial (`actions/*`); permisos del `GITHUB_TOKEN` en `contents: read`.
- Dependabot semanal para dependencias y acciones.

## Compromisos
- El despliegue es automático al fusionar en `main`: rápido, pero exige que `main` esté protegida (se recomienda activar protección de rama).

## Consecuencias
- Cero intervención manual para desplegar; el historial de despliegues queda en GitHub Actions.
