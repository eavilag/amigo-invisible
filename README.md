# 🎁 Amigo Invisible

Aplicación web para organizar un amigo invisible compartiendo **un único enlace por WhatsApp**. Pensada para que la puedan usar personas mayores con poca soltura con el móvil: sin registro, sin contraseñas, letra grande y una sola acción por pantalla.

> **Estado:** fase de especificación y diseño (puertas P1 y P2 en revisión).

## Cómo funciona
1. Quien organiza escribe los nombres y pulsa **Hacer el sorteo**.
2. Envía **un enlace** al grupo de WhatsApp.
3. Cada persona toca el enlace, toca su nombre y ve **a quién regala** y sus ideas de regalo.
